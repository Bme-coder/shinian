AI 服务连接

选择连接方式。API 密钥不会写入 GitHub 源码。

网页源码公开，密钥只在这次打开页面的内存中使用，刷新后要重新输入。整理时，截图与密钥会直接发送给你填写的 AI 服务。请勿在共享设备使用。

服务商必须支持浏览器跨域请求。OpenAI 可直接使用；其他兼容服务若出现跨域错误，请联系服务商或改用服务器代理。

服务器模式适合私有部署。AI_API_KEY 只配置在服务器环境变量中。

默认仅在本次打开期间保留。勾选后保存在当前设备；共享设备请勿勾选。
