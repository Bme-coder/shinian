# 拾念 · 截图到苹果备忘录

用户已确认（2026-11-16）：直接开发可添加到 iPhone 主屏幕的网页 App；输入多张截图及可选描述；使用 OpenAI 或兼容视觉 API；AI 输出标题、摘要、待办、启发及分类；允许编辑后通过快捷指令放入苹果备忘录「灵感收集」文件夹。

## 实现决定
- 新建独立目录 idea-inbox，不改动已有「与神对话」应用。
- 原生 HTML/CSS/ES modules，零生产依赖，中文移动优先，青绿色与暖白色的纸张视觉。
- Node 22+ 服务端和 Vercel Function 共用 AI 处理逻辑；GitHub 托管源码，也可用 GitHub Pages 托管前端并填写后端地址。HTTPS 正式部署后添加主屏幕。服务端保存 AI_API_KEY、AI_BASE_URL、AI_MODEL、APP_ACCESS_TOKEN；手机只填写应用访问口令，绝不保存 AI API 密钥。
- Chat Completions 默认协议，并提供 Responses 可选协议。模型必须支持图片，名称可配置。上传 1–6 张 JPG/PNG/WebP，每张最多 20 MB；压缩普通截图，特别长图按段切分以保留文字可读性；限制请求总大小，提供明确错误及可取消操作。
- AI 严格区分原文事实、推论和建议；看不清时说明，不将截图中的提示视为指令。结果用 JSON 验证，不执行生成内容或 HTML。
- 草稿与历史仅存在设备 IndexedDB；不自动删历史，不存 API 密钥，可导出/导入 JSON 备份和逐条删除。离线可查看/编辑历史，分析需要联网。首次使用明确说明截图只在点击整理后发给所配置服务。
- 默认统一存到「灵感收集」文件夹，用分类文字与 #标签 搜索；不承诺文本 # 自动变成苹果原生智能标签，也不把文本待办冒称为原生可勾选清单。
- 笔记导出为标题、分类、摘要、要点、☐ 待办、启发、原始说明、生成日期。截图保留在 App 草稿中，第一版不自动将图片附件送入 Notes；提供系统分享备选。
- 苹果快捷指令接收剪贴板文本，创建备忘录。提供配置引导及尽可能可导入的 .shortcut，首次指定实际 Notes 文件夹。App 仅报告「已交给快捷指令」，不谎称已写入 Notes。
- 无密钥可使用清晰标记的演示内容预览全流程。演示不触发 API，不与真实结果混淆。

## 完成条件
可运行本地预览；单元/服务端/浏览器交互验证通过；移动布局与离线历史可用；提供安装和部署文档。实际 API 需用户服务端配置密钥；真实 iPhone Notes 需用户安装快捷指令并在手机确认。GitHub 发布在代码和测试完成后连接用户账户。
